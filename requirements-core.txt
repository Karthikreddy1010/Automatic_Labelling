# PoleAnnotator AI -- CORE dependencies (annotation workspace only)
# =================================================================
#
# This is everything the app needs to START and to run the complete manual
# labeling workflow:
#
#   import images -> draw / edit / rotate 4-corner OBBs -> review, accept,
#   reject, skip -> active-learning tags -> dataset balance & coverage ->
#   export YOLO-OBB -> guided tour
#
# Measured install footprint: ~330 MB in a clean virtualenv, against the
# several GB the full ML stack needs (torch + CUDA wheels alone dwarf it):
#
#     pip install -r requirements-core.txt
#     python run_backend.py
#
# What you do NOT get with core-only: the AI buttons (AI Label, Run All,
# Batch Engine, Refine SAM). Those report "model not installed" in the UI and
# return HTTP 503 from the API -- they never crash the server. Add them with:
#
#     pip install -r requirements.txt        # full stack: torch, DINO, SAM, Qwen
#
# requirements.txt is a strict superset of this file; the pins match it
# exactly, so installing both in either order is consistent.
